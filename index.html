🖥️ Javascript

Javascript es un lenguaje de programación dinámico y de alto nivel para crear interfaces interactivas y dinámicas.

Es uno de los tres pilares fundamentales del desarrollo web.

  • 1️⃣ HTML. Define la estructura del contenido. Son los elementos que aparecen en la página
  • 2️⃣ CSS. Define la apariencia. Colores, tamaños, estilos, etc.
  • 3️⃣ Javascript (JS) Define el comportamiento. Lo que hace la página o sus elementos.

Características de Javascript

  1. 👉 Lenguaje intepretado. No necesitamos compilarlo. El navegador lo entiende directamente.
  2. 👉 Basado en objetos. Maneja objetos como document, window, arrays, date, class.
  3. 👉 Dinámico. Podemos modificar el contenido en tiempo real. (Sin recargar)
  4. 👉 Versatil y de fácil aprendizaje. Aunque nacio para la web, se usa también en servidores, aplicaciones móviles, videojuegos y hoy en día en Inteligencia Artificial.

Integración de Javascript JS

Hay tres formas principales de integrar Javascript en una página web:

  • 1️⃣ Directamente en el HTML. Usando la etiqueta <script></script> dentro del archivo HTML.
  • 2️⃣ Archivo externo. Vinculando un archivo .js con la etiqueta <script src="ruta/del/archivo.js"></script> antes del cierre de la etiqueta </body>.
  • 3️⃣ Archivo externo en el head. Vinculando un archivo .js dentro de la etiqueta <head> con el atributo defer para que espere a que se cargue el HTML antes de ejecutarse.

La opción recomendada es la segunda o tercera, ya que permite mantener el código separado del HTML, facilitando su mantenimiento y reutilización.
